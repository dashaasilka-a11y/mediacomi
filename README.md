# Медиакоми — Симулятор оценки недвижимости

Интерактивный сервис для проверки навыка оценки стоимости квартир по фото и описанию.

## 🎮 Механика

1. **Старт** — главная страница с описанием сервиса
2. **10 раундов** — случайные квартиры из базы объявлений
3. **Итог** — результат с категорией инвестора

### Система баллов

| Точность угадывания | Баллы |
|---|---|
| ≤ 5% | 10 |
| ≤ 10% | 8 |
| ≤ 15% | 7 |
| ≤ 20% | 6 |
| ≤ 30% | 4 |
| ≤ 50% | 2 |
| > 50% | 1 |

### Результат

- 💎 **«Щедрый инвестор»** — в среднем переплачиваете (> +15%)
- 🎯 **«Открытый инвестор»** — приближено к реальной цене (±15%)
- 🪙 **«Скряга»** — в среднем недоплачиваете (< -15%)

## 🚀 Запуск

```bash
npm install
npm run dev
```

## 📦 Сборка

```bash
npm run build
```

Результат в папке `dist/`.

## 🌐 Деплой

Проект — статический SPA. Деплоится на любой хостинг:
- **Vercel**: `vercel deploy`
- **Netlify**: перетащить `dist/` в панель
- **GitHub Pages**: загрузить `dist/` в ветку `gh-pages`

## 🛠 Технологии

- React 18 + TypeScript
- Vite
- Tailwind CSS 4
- Основной цвет: `#26CD94`

## 🔒 Безопасность

Security headers настроены через `<meta>` теги:
- Content-Security-Policy
- X-Frame-Options: DENY
- X-Content-Type-Options: nosniff
- Referrer-Policy: strict-origin-when-cross-origin
- Permissions-Policy

## 📱 Приоритет

- Mobile-first дизайн
- Один экран = одна карточка
- Минимальный трафик (lazy loading изображений)
- Без тяжёлых библиотек
